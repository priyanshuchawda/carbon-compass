## Technical Highlights

1. **Zero-Flicker Progressive Render**: The assistant insight component displays clean, local rule-based advice immediately. It triggers a fetch to the Gemini route in the background, rendering conversational narrations progressively once returned.
2. **API Cost Tracking**: The `/api/assistant/chat` and `/api/assistant/narrate` routes inspect token metadata returned in the API response headers to compute usage cost in USD.
3. **Automated Verification**: Run `pnpm quality` to execute linting, typechecks, Vitest unit testing, and Next.js compiler builds.
4. **Offline and Fallback Capabilities**: The application is resilient to network issues. If the Gemini API is offline, rate-limited, or lacks keys, the offline assistant fallback uses actual user category inputs, potential savings, and household size to output per-capita averages and tailored advice.
